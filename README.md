# 💫 About Me:
Android developer with 4+ years of experience shipping production apps across e-commerce, delivery, social, and IoT/vending-machine control domains. I build with Kotlin, Java, and Jetpack Compose, following MVVM architecture, and integrate Firebase, REST APIs, and payment/ad SDKs end-to-end.<br><br>What I've done:<br><br>• Designed and shipped real-time control and diagnostics features for an IoT vending-machine platform using Jetpack Compose and SDK-driven API integrations<br><br>• Built and maintained apps across e-commerce, delivery, dating, and chat categories, from UI to backend integration to Play Store deployment<br><br>• Delivered Firebase integration, offline databases, push notifications, and ad monetization (AdMob) for freelance clients on Fiverr<br><br>• Received the Proactive Excellence Award at Preesoft for performance and initiative beyond core engineering work<br><br>I care about clean architecture, maintainable code, and good UX, and I write about Android's history and fundamentals to stay sharp and help other developers learn.<br><br>Open to Android engineering roles where I can take ownership of features end-to-end.
